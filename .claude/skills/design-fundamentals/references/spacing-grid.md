# 余白とグリッド — 間隔は「段」から選ぶ

> 出典: Josef Müller-Brockmann『Grid Systems in Graphic Design』（グリッドで配置の判断を減らす）、『Refactoring UI』（余白は多めから始めて削る／値は決めた段から選ぶ）、Material Design・Apple HIG のレイアウト指針。

## 原則と当てる問い

### 1. 余白の値は「段（スケール）」から選ぶ

その場で 13px や 21px を決めない。**決めた段からだけ選ぶ**（例: 4 の倍数・8 の倍数の段。どの段にするかはプロジェクトが決める）。段が決まっていれば、近接の「小さい間隔／大きい間隔」が自動的に区別できる。

- この画面の間隔は、決めた段の値だけでできているか
- 段の値が近すぎて、差が見分けられない組み合わせを使っていないか（隣り合う段は、はっきり違う比にする）

### 2. 余白は多めから始めて、削る

窮屈な画面を後から広げるより、広い画面を詰めるほうが崩れにくい。

- 節の切れ目は、要素間の間隔よりはっきり広いか（本文「近接」）
- 「埋まらなかった余り」の空白になっていないか（余白は区切りの道具として配る）

### 3. グリッドで揃える

列（カラム）と外側の余白（マージン）、列間（ガター）を決め、要素をそこに乗せる。

- 画面の左右の余白は、全画面で同じ値か
- 横並びの要素は、同じ列の線に乗っているか
- 画面幅が変わったとき、列数をどう変えるかを決めたか（並びが折り返す幅・1列になる幅）

### 4. 入れ物の内側の余白

- ボタンやカードの内側の余白は、外側の間隔より小さいか（内側が外側より広いと、中身が外に属して見える）
- 同じ種類の入れ物の内側の余白が揃っているか

## よくある壊れ方

- 自動レイアウトで中身に合わせたら、画面ごとに下端の位置がずれた（可変余白を固定値のまま放置）
- 内側の余白と外側の間隔が同じで、カードの境目がぼやけた
- スマホ幅だけ左右の余白が違う
- 決めた段にない半端な値（例: 11px、15px）が混ざっている
