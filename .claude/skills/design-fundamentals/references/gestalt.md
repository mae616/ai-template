# ゲシュタルト — 人は部品ではなく「まとまり」を見る

> 出典: ゲシュタルト心理学の知覚の法則（Wertheimer ほか）。UI向けの整理は Jon Yablonski『Laws of UX』（lawsofux.com）の Law of Proximity / Similarity / Common Region / Uniform Connectedness / Prägnanz。

**使いどころ**: 本文の「近接」で足りないとき。距離以外の手がかり（形・色・囲み・線）で、まとまりが意図どおりに見えているかを確かめる。

## 法則と当てる問い

| 法則 | 何が起きるか | 当てる問い |
|---|---|---|
| 近接 | 近いものは仲間に見える | 本文「近接」を参照 |
| 類同 | 色・形・大きさが似ているものは、離れていても仲間に見える | 違う役割のものが、同じ色・形になっていないか。同じ役割なのに、色や形が割れていないか |
| 共通領域 | 同じ枠・同じ背景の中にあるものは仲間に見える | 枠や背景の面は、本当に仲間をまとめているか。無関係なものが同じ面に同居していないか |
| 結合 | 線や面でつながったものは、つながっていないものより強く仲間に見える | 線でつないだものは本当に関係があるか。区切り線が、まとめたいものを逆に分断していないか |
| 閉合 | 欠けた形も、閉じた形として補って見る | 囲み線を全部描かなくても、余白と揃えでまとまりが見えないか（線を減らせないか） |
| 連続 | 滑らかにつながる線や並びは、一続きに見える | 視線の流れは途切れずに次の要素へ続くか。並びの途中で向きや揃えが変わっていないか |
| 図と地 | 前にあるもの（図）と背景（地）を分けて見る | 主役は背景から浮いて見えるか。背景が主役と同じくらい主張していないか |
| 簡潔性（プレグナンツ） | 曖昧な形は、いちばん単純な形として解釈される | その形は一番単純な読み方で、意図どおりに読まれるか |

## 強さの順（ぶつかったとき）

まとまりの手がかりが食い違うと、**囲み（共通領域）と結合は、近接や類同より強く効く傾向がある**（Stephen Palmer による共通領域・均一結合の研究）。

- 近くに置いたのに枠が別 → 枠のほうが勝つ。別のものに見える
- 枠で囲ったのに、中の間隔が枠の外より広い → まとまりが崩れる

⚠️ だから枠（カード）は最後の手段にする。**まず余白と揃えでまとめ**、それでも足りないときだけ面や線を使う（`art-direction` の引き算と同じ向き）。

## よくある壊れ方

- カードを並べたら、カードの中の間隔とカード同士の間隔が同じになった
- 押せるボタンと押せないラベルが、同じ色・同じ形で並んでいる（類同で同じ物に見える）
- 区切り線を多用して、まとめたいものまで切ってしまった
- 背景の模様や写真が強く、文字が「地」に沈んだ
