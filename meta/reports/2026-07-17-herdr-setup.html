Setup Report

herdr で Claude の変更差分をプロジェクト単位でレビューできるようにした

2026-07-17 ・ macOS / Homebrew ・ herdr 0.7.1

ゴールは「Claude などのエージェントが触ったファイルを、herdr の画面の中でそのまま差分レビューできる」こと。 差分ビューア hunk とファイルビューアの2つのプラグインを導入し、キーバインドを設定した。 Claude 統合はすでに最新だったため追加作業なし。

01全体の構成 — 何がどう繋がっているか

Claude Code がプロジェクトのファイルを編集すると、その変更は git の worktree（未コミットの作業ツリー）に現れる。 hunk がそれを watch し、herdr の split ペインに差分として表示し続ける、という流れ。

03設定したキーバインド

prefix キーを押して prefix モードに入ってから、以下のキーを押す。

キー動作用途
prefix → h hunk を split で起動（worktree diff・watch状態） Claude が今なにを変更したかをリアルタイムで見る
prefix → f ファイルビューアを split で起動 プロジェクト全体の構成を横目で確認
prefix → Shift+F ファイルビューアを新しいタブで起動 広い画面でじっくりツリーを見る

05補足 — 差分の見方は3モードある

  • worktree（今回キーに割り当てたもの）— コミットしていない変更すべて。Claude の作業を追うならこれ。
  • staged — git add 済みの変更だけ。コミット前の最終確認向け。
  • branch — main（または master）との差分全体。ブランチ単位のレビュー向け。

staged / branch もキーに割り当てたい場合は、config.toml の [[keys.command]] に hunk.diff.staged-split や hunk.diff.branch-split のアクションを追加すればよい。

herdr を介さずに、任意のペインで hunk を直接起動しても同じ差分ビューが使える。 エージェントの変更を「レビューして承認する」用途に特化したツールなので、lazygit 等よりこの目的には合っている。
