# デザインドック（主題ごとの決めごと）

> ここには「**決まっていること**」と「**なぜそうなっているか**」だけを書く。書き方は `design-doc` スキル。
> 値（色・サイズ・文言の実体）は書かない → `doc/input/design/*.json`。経緯は書かない → コミットメッセージ。

## 索引（いまやっていること → 読むドック）

| いまやっていること | 読むドック |
|---|---|
| （主題を足したらここに1行足す） | — |

## 主題の一覧

| ファイル | 主題 | 状態 |
|---|---|---|
| （まだ無い） | — | — |

主題は画面ではなく**論点**で切る（例: 出口と戻り／ボタンとリンク／アイコン／言葉づかい／確認と警告／色と文字／モーション）。最初の5画面で出た論点で決める。

## 1本の形

```markdown
# {主題}

> 最終更新: YYYY-MM-DD

## 決まっていること      ← 結論。表で引ける
## なぜそうなっているか   ← 考慮した制約。ここが本体
## 当てるときの手順       （要るときだけ）
## 迷ったときの分岐       （要るときだけ）
## まだ決めていない       ← 空にしない。無ければ「なし（YYYY-MM-DD 時点）」
```
