# ai-template への送り状（発: {プロジェクト名}）

> **これは何**: このプロジェクトで得た「汎用化できる学び」を、コピー元の `ai-template` に渡すための送り状（outbox）。
>
> **運用プロトコル（競合回避モデル）**:
> 1. 各プロジェクトは、自分のrepo内のこのファイルに**汎用学びを記録するだけ**。`ai-template` を直接編集しない（複数プロジェクトの同時編集による競合を原理的に防ぐ）。
> 2. 取り込みは `ai-template` 側で行う: `ai-template` フォルダで Claude を開き `/template-feedback` を実行。sibling プロジェクトの送り状（`../*/doc/output/to-template.md`）を走査・統合・競合解決し、template の skill/rule/CLAUDE.md に反映する（判断を1か所に集約＝直列処理＝競合しない）。
> 3. 反映が済んだ項目は、取り込み側がこのファイルの「状態」を `取込済（YYYY-MM-DD / templateコミット短縮hash）` に倒す。**二重取り込み防止**の台帳として機能させる。
>
> **項目フォーマット（固定）**: 種別 / 汎用化した形 / 反映先候補 / 出典 / 状態。
> プロジェクト固有の表現（色・画材・フォント名等）は**載せない**。汎用化できるものだけ。
